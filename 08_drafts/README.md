# Черновики

Раздел для согласованных к публичному размещению текстов глав и презентаций. В версии 0.1 тексты ранее созданных документов не загружены и не восстановлены дословно.

Перед добавлением: проверить источники, отделить авторские предложения от фактов, удалить персональные и непубличные сведения, проверить права на публикацию. Материал со статусом «черновик» не считать утверждённым выводом диплома.
