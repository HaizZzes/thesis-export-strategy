# План апробации

Статус: эксперимент не проведён, результаты отсутствуют.

## Дизайн

Сопоставить базовый и предлагаемый порядок подготовки одного и того же управленческого решения на одинаковом разрешённом наборе данных. Если используются синтетические материалы, явно обозначить их происхождение.

## Показатели-кандидаты

| Показатель | Способ измерения | Ограничение |
|---|---|---|
| Полнота оснований | Заполненные обязательные поля / все обязательные поля | Заполнение не равно качеству |
| Прослеживаемость | Выводы с проверяемыми основаниями / проверяемые выводы | Нужна оценка релевантности источников |
| Время подготовки | Фактически измеренная длительность сопоставимых заданий | Нужны одинаковые условия |
| Исправления | Число существенных ошибок по заранее заданной рубрике | Нужны единые критерии |

Набор полей и критерии ошибок фиксируются до эксперимента. Нулевые знаменатели отмечаются как «не применимо». Не выводить рост экспортных продаж из улучшения промежуточных показателей. Синтетический кейс проверяет работоспособность подхода, но не доказывает эффект в реальной организации.
