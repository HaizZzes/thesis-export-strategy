# Ресурсы и источники

## Начальные точки поиска

Следующие адреса — навигационные ресурсы, а не подтверждение конкретных тезисов. Содержание и актуальность страниц в этой версии отдельно не проверялись.

## Реестр доказательных источников

Пока не заполнен. Включать конкретные документы, а не только главные страницы сайтов.

Поля записи: ID; полное название; автор или организация; дата; редакция; точная ссылка; страницы или пункты; дата фактической проверки; поддерживаемый тезис; ограничения; статус трёх проверок.

Корпоративная публикация может подтверждать факт публичного заявления организации, но сама по себе не доказывает независимую оценку эффективности. Статьи оцениваются по содержанию и методологии, а не только по наличию в базе.
