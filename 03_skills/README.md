# Скиллы для ИИ

Скилл — инструкция для повторяемой исследовательской задачи. Наличие инструкции не означает, что у ИИ автоматически появились поиск, доступ к документам или полномочия совершать действия.

- [Проверка источников](source-verification/SKILL.md)
- [Научный анализ и письмо](research-writing/SKILL.md)

План расширения: обзор литературы, правовой анализ, анализ управленческих процессов и проверка расчётов. До создания отдельных инструкций эти направления не считаются готовыми скиллами.
