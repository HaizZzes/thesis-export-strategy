# Тематическая база знаний

Пока это программа наполнения, а не набор доказанных отраслевых выводов.

| Направление | Что изучаем | Связь с дипломом |
|---|---|---|
| Стратегическое планирование | Цели, горизонт, сценарии, распределение ответственности | Основа механизма |
| Экспортное продвижение | Различия планирования, маркетинга и исполнения поставки | Уточнение предмета |
| Жизненный цикл продукта | Моменты фиксации требований и обратная связь | Ранняя экспортная оценка |
| Корпоративное управление | Полномочия, согласования, контрольные точки | Организационная реализуемость |
| Цифровые технологии | Качество данных, реестры, аналитика, поддержка решений | Выбор инструментов под задачу |
| Регулирование и безопасность | Применимые нормы и режимы доступа | Ограничения проектирования |

Каждая будущая заметка должна содержать вопрос, тезисы, источники, статус проверки и связь с конкретной задачей исследования. Реальные процессы организаций описываются только при наличии надёжных открытых подтверждений.
