# Методология и проверка

Статус: предлагаемый дизайн исследования.

## Последовательность

1. Сформулировать вопросы и критерии проверки гипотезы.
2. Задать правила отбора литературы и открытых документов.
3. Выполнить обзор и зарегистрировать подтверждённые положения.
4. Описать базовый процесс на доступных доказательствах. При их недостатке использовать явно обозначенную модель, не называя её реальным процессом организации.
5. Разработать авторскую модель и критерии сопоставления.
6. Провести апробацию, проверить чувствительность выводов к допущениям.
7. Зафиксировать результаты, альтернативные объяснения и ограничения переноса.

## Методы-кандидаты

- Структурированный обзор литературы: определить поисковые запросы, базы, период и критерии исключения.
- Сравнительный анализ процессов: использовать одинаковую единицу анализа и границы.
- Сценарный анализ: документировать предпосылки, не выдавать сценарии за прогноз.
- Экспертная оценка: только при фактическом проведении, согласованном составе и описанном протоколе.
- Анализ чувствительности: менять допущения и проверять устойчивость выводов.

## Контроль качества

Проверка первоисточника → независимое сопоставление → проверка актуальности и интерпретации. Для каждого этапа фиксировать результат, а не автоматически ставить отметку «проверено». Противоречащие гипотезе данные сохранять.
